# Anonymous Replication Package

This package supports replication of the study-selection and screening process for a scoping review on large language models in static software analysis.

All package documentation, file names, sheet names, column headers, status labels, and screening rationales are in English. Author and institutional identities are intentionally omitted.

## Contents

- `data/llm_static_analysis_review_data_anonymized.xlsx`: primary anonymized workbook.
- `data/csv/`: machine-readable CSV exports of each worksheet.
- `documentation/DATA_DICTIONARY.md`: variable and file descriptions.
- `documentation/ANONYMIZATION.md`: anonymization and language-cleaning procedure.
- `manifest_sha256.csv`: checksums for integrity verification.

## Replication Use

Use the protocol sheet to verify the research questions, search string, and inclusion/exclusion criteria. Use the screening sheets to reproduce candidate-study selection decisions.
