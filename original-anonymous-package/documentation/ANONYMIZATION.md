# Anonymization and Language-Cleaning Procedure

The original workbook is not redistributed. The delivered workbook was rebuilt from screened cell values and normalized into an English-only package.

Removed or neutralized:

- package-author names and group names;
- course/class references;
- local filesystem paths;
- e-mail patterns;
- original drawings/images;
- workbook person metadata, comments, and original package relationships;
- Portuguese worksheet names, column headers, status labels, and screening rationales.

Retained:

- bibliographic author names of the reviewed studies;
- paper titles, DOIs, venues, screening decisions, mapped research questions, and criterion-level rationales necessary for replication.

Final checks scan workbook cells, CSV files, documentation, and internal `.xlsx` XML files for package-author identifiers, local paths, common Portuguese screening terms, and metadata containers.
